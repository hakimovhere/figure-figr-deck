# Figure Technology (Nasdaq: FIGR): should a fund buy the stock?

Group presentation for **DTF-2 Blockchain and Cryptocurrency Markets** (Michael Halling, University of Luxembourg), 20 November 2026.

**Open the deck:** https://hakimovhere.github.io/figure-figr-deck/

**Our answer:** a great, fast-growing lender, but at $25.67 the stock costs 18–27 times profit while fees per loan fall. Do not invest now; keep it on a watch list.
